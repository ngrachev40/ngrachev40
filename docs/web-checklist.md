# Web Checklist (Online Store)

## Описание
Чек-лист для тестирования интернет-магазина.

## Проверяемые функции

### Главная страница
- Загрузка страницы
- Корректность отображения элементов
- Проверка баннеров и ссылок

### Каталог товаров
- Отображение списка товаров
- Фильтрация
- Сортировка
- Пагинация

### Карточка товара
- Название
- Цена
- Фото товара
- Кнопка "Добавить в корзину"

### Корзина
- Добавление товара
- Удаление товара
- Изменение количества
- Пересчёт итоговой суммы

### Оформление заказа
- Заполнение формы
- Проверка обязательных полей
- Подтверждение заказа
