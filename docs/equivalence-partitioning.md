# Equivalence Partitioning

## Описание
Пример применения техники эквивалентного разбиения для проверки поля "Возраст".

---

## Требование
Поле "Возраст" принимает значения от 18 до 60.

---

## Классы эквивалентности

### Валидные значения
- 18
- 25
- 45
- 60

### Невалидные значения
- 17 (меньше минимального)
- 61 (больше максимального)
- 0
- -5
- пустое значение
- текст ("abc")

---

## Вывод
Техника позволяет сократить количество тестов, сохранив покрытие основных сценариев.
