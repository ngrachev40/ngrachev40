# Test Cases

## Описание
Набор тест-кейсов для проверки пользовательских сценариев.

---

## TC-001 Авторизация с валидными данными

**Предусловие:** пользователь зарегистрирован

**Шаги:**
1. Открыть страницу логина
2. Ввести валидный email
3. Ввести корректный пароль
4. Нажать "Войти"

**Ожидаемый результат:**  
Пользователь успешно входит в систему.

---

## TC-002 Авторизация с неверным паролем

**Предусловие:** пользователь зарегистрирован

**Шаги:**
1. Открыть страницу логина
2. Ввести валидный email
3. Ввести неверный пароль
4. Нажать "Войти"

**Ожидаемый результат:**  
Появляется сообщение об ошибке.

---

## TC-003 Добавление товара в корзину

**Шаги:**
1. Открыть карточку товара
2. Нажать "Добавить в корзину"

**Ожидаемый результат:**  
Товар появляется в корзине.
