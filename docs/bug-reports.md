# Bug Reports

## Описание
Примеры оформления баг-репортов.

---

## BUG-001 Не работает кнопка "Войти"

**Severity:** Critical  
**Priority:** High

**Шаги воспроизведения:**
1. Открыть страницу логина
2. Ввести валидные данные
3. Нажать кнопку "Войти"

**Фактический результат:**  
Ничего не происходит.

**Ожидаемый результат:**  
Пользователь входит в систему.

---

## BUG-002 Некорректное сообщение об ошибке

**Severity:** Minor  
**Priority:** Medium

**Шаги воспроизведения:**
1. Открыть форму регистрации
2. Оставить обязательные поля пустыми
3. Нажать "Зарегистрироваться"

**Фактический результат:**  
Сообщение об ошибке отображается некорректно.

**Ожидаемый результат:**  
Показывается понятное сообщение для пользователя.
